# Project Time Record

This document defines the time-tracking policy for the project.

Detailed historical development hours were not reconstructed retrospectively because exact start and end times were not consistently recorded during the earliest development stages.

Invented or estimated session times are intentionally not presented as precise records.

## Development Categories

Project work includes:

- planning and research
- coding and implementation
- testing and validation
- debugging and revision
- experimental execution and analysis
- 3D and interface development
- documentation and presentation

## Recording Policy

Any future time entries should be recorded prospectively and should include only directly supported information.

Recommended fields are:

| Date | Category | Duration | Work Completed |
|---|---|---:|---|

This file is maintained for transparency rather than to reconstruct unsupported historical time data.
