# 3D Emergency Evacuation Strategy Simulator

Research-oriented software for experimentally evaluating evacuation routing strategies under dynamic building conditions.

## Project Principle

The research engine is developed first. The 3D environment serves as an interactive visualization of the same underlying simulation and decision models used by the experimental engine.

## Planned Capabilities

- Agent-based pedestrian evacuation simulation
- Multiple routing strategies
- Dynamic congestion and route conditions
- Blocked exits and hazardous areas
- Adaptive rerouting
- Reproducible seeded experiments
- Automated batch experiments
- Statistical and comparative analysis
- Interactive 3D visualization
- Local demonstration
- Optional live web deployment

## Status

Research model definition and parameter validation.
